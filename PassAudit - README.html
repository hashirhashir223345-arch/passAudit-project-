PassAudit

A read-only password policy auditor for Windows, written in Python. It collects the local password policy (and, in a lab domain, the domain password policy), compares every setting with a written baseline, and prints a graded PASS / WARN / FAIL report with a risk explanation for each weak setting.

Lab use only. Run PassAudit only on systems you own or have written permission to examine. It only reads policy settings; it never changes a password, a policy or an account. Unauthorized access to computer systems is a criminal offence under the Prevention of Electronic Crimes Act, 2016 (Pakistan).

What it checks

Check Source of the value
Minimum password length net accounts / LDAP minPwdLength
Password complexity secedit /export / LDAP pwdProperties (bit 1)
Maximum password age net accounts / LDAP maxPwdAge
Minimum password age net accounts / LDAP minPwdAge
Password history length secedit /export / LDAP pwdHistoryLength
Account lockout threshold net accounts / LDAP lockoutThreshold
Account lockout duration net accounts / LDAP lockoutDuration
Lockout observation window net accounts / LDAP lockOutObservationWindow
Reversible encryption secedit /export / LDAP pwdProperties (bit 16)

A setting that cannot be read is graded FAIL (it cannot be treated as safe).

Baseline

Setting PASS WARN FAIL
Minimum password length >= 14 8-13 < 8
Complexity Enabled - Disabled
Maximum password age 1-365 days 366-730 days Never expires, or > 730
Minimum password age >= 1 day - 0
Password history >= 24 10-23 < 10
Lockout threshold 1-5 attempts 6-10 0 (never locks) or > 10
Lockout duration >= 15 min 5-14 < 5
Lockout observation window >= 15 min 5-14 < 5
Reversible encryption Disabled - Enabled

Where the values come from: the CIS Microsoft Windows Benchmarks (Account Policies section) and Microsoft security guidance. The PASS column follows the CIS recommended values; the WARN bands are my own "close but short" ranges. The exact value for each check is encoded in baseline.py, together with its source and risk text.

Notes on the baseline:

  • Maximum password age follows CIS (365 days or fewer, not 0). Microsoft's newer security baselines and NIST SP 800-63B no longer recommend forced periodic expiry, so treat this check as a CIS-driven requirement, not a universal one.
  • When the lockout threshold is 0, lockout duration and window are not enforced in practice.

Install

Python 3.8+ on Windows. Local mode uses only the standard library. Domain mode needs ldap3:

pip install -r requirements.txt

Run

Open an elevated (Administrator) prompt, because secedit /export needs it.

:: local policy only
python passaudit.py --mode local

:: local policy + lab domain policy over LDAP
python passaudit.py --mode domain --server dc01.lab.local --base-dn "DC=lab,DC=local" --user "LAB\student"

:: choose the report name (the audit date is added automatically)
python passaudit.py --mode local --output reports\vm_audit.txt
  • The LDAP password is asked at the prompt (or set PASSAUDIT_LDAP_PASSWORD). It is never a command-line flag.
  • Use --ssl for LDAPS.
  • Reports are saved as name_YYYYMMDD_HHMMSS.txt. An earlier report is never overwritten.
  • Exit code 0 = no failures, 1 = at least one FAIL.

Limitations: net accounts parsing expects English Windows output.

Project layout

File Job
passaudit.py command-line entry point
collectors.py net accounts, secedit and LDAP readers (read-only)
baseline.py the baseline data: values, risks, sources
grader.py PASS / WARN / FAIL logic
report.py report text, summary, safe saving
tests/ unit tests (no Windows needed)

Tests

python -m unittest discover -s tests -v

The grader is tested with a strong, a borderline and a weak policy record; the parsers are tested with sample net accounts, secedit and LDAP data.
